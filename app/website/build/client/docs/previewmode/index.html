preview 模式

饰品截图模式，含景深、FOV 调节、摄像机锁定

设置文件：srp-cfg/modes/preview/settings.cfg

简介

preview 模式提供饰品截图专用的预设环境。加载后自动关闭 HUD、开启景深效果、拉长 FOV、固定摄像机视角，方便拍摄饰品检视截图。

需要在自建房或作弊服务器中使用（需要 sv_cheats 权限）。

激活方式

推荐输入 srp_preview，只应用预览模式设置。需要快捷键表时输入 srp_preview_keys，它会额外重绑方向键、-、=、Z/X/C/V；Default 案例中的 9 键调用该命令。

首次加载预设

加载时自动应用以下设置：

预设项初始状态说明
HUD关闭消除界面干扰，画面更干净
景深 (DOF)开启模拟相机虚化效果，突出饰品主体
FOV110拉长视角，显示更多画面
摄像机固定视角不会随鼠标移动，便于构图

可选按键表

下表快捷键仅在执行 srp_preview_keys 后生效。使用 srp_preview 时，可通过 settings 文件定义的 alias 或控制台命令操作，不会自动占用这些实体键。

功能快捷键控制台别名
FOV 视角调节↓changefov
向左旋转视角-changeang--
向右旋转视角=changeang++
开关 HUDzsrp_preview_hud
是否固定摄像机视角xsrp_preview_lock
是否开启景深csrp_preview_dof
调节景深深度vchangeblur
恢复默认设置-depre

景深参数说明

按 v 键循环切换以下景深深度：

深度值效果
50极浅景深，背景严重虚化
100浅景深
500中等景深
1000默认景深，推荐使用
3000极深景深，画面几乎全清晰

恢复正常

控制台输入 depre 可一键恢复所有设置为默认状态（HUD 开启、景深关闭、FOV 重置、摄像机解锁）。

相关文件

  • autoexec.cfg — v3 Runtime、内置 Preset 与用户层入口

注意事项

  • 仅在自建房/作弊服务器中有效（需要 sv_cheats 1）
  • 恢复默认请使用 depre 命令，而非手动逐项调整
  • _keys 入口产生的实体绑定会进入 user keys VCFG；depre 恢复画面设置，不负责恢复全部按键
