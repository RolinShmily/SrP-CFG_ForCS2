01Architecture

不是一包偏好，而是一套边界明确的运行时

v3 把“功能实现”“可选案例”“个人差异”和“游戏持久状态”拆开。每一层只有一个主人，也只有一种职责。

Runtime Core

项目维护

02Quick start
先看懂流程，再开始部署下载、检测、选择来源、确认目标与建立 custom.cfg，被拆成五个可以逐项核对的步骤。
03Download
只需要一个 Runtime Core功能、用户入口、Preset 案例与 Valve 重置基线进入同一个 v3 配置包。
04Install
路径、账号与 VCFG 状态同屏确认安装前先明确游戏 CFG、Annotations、Video 与账号本地配置的真实位置。
05Recovery
恢复对象各归其位上一个 Runtime、安装前原文件与只读 VCFG 快照分开呈现，用户配置始终受保护。
06Managed files
安装器只管理自己部署的文件当前安装清单可审计、可分类移除，不把 custom.cfg 或游戏持有的 VCFG 混入其中。
07About
项目边界与来源保持可追溯官网、仓库、技术栈、维护者与许可证都能从应用内直接找到。
03Workflow

四步开始，每一步都能解释

自动化不等于隐藏行为。v3 让安装、选择、覆盖和重置都有可检查的文件与命令。

  1. 01 / 04

    获取

    SrP-CFG_Runtime_Core.zip

    下载唯一 Runtime Core，或通过 Desktop 在应用内获取。没有用户专属发行包需要选择。

  2. 02 / 04

    部署

    game/csgo/cfg/

    确认 Steam 账号和路径，默认把 Runtime 部署到游戏 CFG 目录；冲突原文件进入恢复中心。

  3. 03 / 04

    选择

    user/custom.cfg

    保持 VCFG 托管，或选择一个 srp_apply_* 起点，再把自己的灵敏度、按键与偏好写在下面。

  4. 04 / 04

    迭代

    srp_reload

    游戏内继续调试；需要确定性持久化的差异写回 custom.cfg，需要纯基线时执行 srp_reset_valve。

Ready when you are
